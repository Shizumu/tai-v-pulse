# 台V Pulse

台V Pulse 是一套只在本機執行的台灣 VTuber YouTube 數據工具。它會尋找頻道名稱、頻道說明或頻道關鍵字中自述「台V」、「台灣 VTuber」或「Taiwan VTuber」的頻道，並只自動收錄公開訂閱數至少 1,000 的頻道。

## 第一次使用

1. 在 Google Cloud 建立專案並啟用 YouTube Data API v3。
2. 建立 API Key，但不要把 Key 貼到聊天或提交到版本控制。
3. 執行 `start-local.ps1`。第一次會建立並開啟 `.env`。
4. 將 Key 填入 `YOUTUBE_API_KEY=` 後儲存，再執行一次 `start-local.ps1`。
5. 瀏覽器會開啟 `http://localhost:3000`，按「探索台 V 頻道」。

停止服務時執行 `stop-local.ps1`。

## 指定頻道與誤判排除

- 「探索台 V 頻道」是大範圍搜尋，但只自動收錄頻道名稱、說明或關鍵字中自述為台 V，且公開訂閱數達 1,000 的頻道。
- 「指定 VTuber 搜尋」可輸入頻道名稱、`@handle`、Channel ID 或頻道網址。指定收錄不要求台 V 自述字樣，但仍須公開訂閱數達 1,000。
- 已收錄頻道右側的「排除」會刪除該頻道的本機影片、統計與同接資料，並加入黑名單，之後大範圍探索不會自動加回。
- 若要收回黑名單頻道，可再次指定搜尋並按「重新收錄」。

## 網頁內調整規則

在「收錄規則」右上角按「編輯」，可直接修改：

- 大範圍探索字樣
- 最低訂閱數
- 同接更新秒數
- 頻道統計更新間隔
- 最新上傳掃描間隔
- 資料保留天數

設定會保存在本機 SQLite 資料庫，重新啟動後仍會沿用。修改最低訂閱數或探索字樣只影響之後的探索與指定收錄，不會自動刪除既有頻道。

## 分類、排序與詳細頁

- 已確認頻道可設為「未分類、個人勢、企業勢、團體勢、其他」，也能在頻道詳細頁輸入自訂分類。
- 頻道列表可依分類篩選，並依訂閱數、總觀看、影片數、分類、名稱或最近更新排序。
- 點擊頻道名稱可開啟詳細頁，查看訂閱趨勢、總觀看、影片與直播統計、最高同接及收錄資訊。
- 趨勢與最高同接必須先累積至少兩次統計快照或直播輪詢，剛收錄時可能暫時沒有圖表。

## 內容環境與同量級分析

從首頁右上角進入「內容環境」，可用以下方式建立比較群組：

- 全部已收錄頻道
- 指定一個參考頻道，自動比較訂閱數為其 0.5～2 倍的頻道
- 固定訂閱級距：1,000～5,000、5,000～10,000、1 萬～5 萬、5 萬～10 萬、10 萬以上
- 再依頻道分類及最近 7、30、90 天篩選

內容環境會分析同級中位數及前 25%、每週發布頻率、觀看／訂閱比、直播同接／訂閱比、內容類型占比、直播時段熱圖、近期主題標籤、高效率內容和同級頻道案例。

內容主題由公開標題、說明、標籤及影片分類推測，目前包含遊戲、雜談、歌回、ASMR、聯動、音樂作品、紀念／重大活動與其他；內容形式則分為直播、一般影片與 Shorts。這是可檢查的規則分類，不是 YouTube 官方 Analytics 分類。

程式會在後續影片更新時保存觀看、喜歡及留言快照。剛啟用時，既有影片只有目前值；持續運行後才會形成可靠的期間變化。

## 預設規則

- 訂閱門檻：1,000
- 同接更新：每 60 秒，最多 50 支直播合併成一次 API 請求
- 頻道統計：每 6 小時
- 最新上傳掃描：每 4 小時，分批執行
- API 一般配額安全保留：10%
- 原始統計保留：30 天
- 隱藏訂閱數：放入待審核，不自動收錄

所有設定都在 `.env`。取得 YouTube 相應的長期統計保存許可後，可將 `RETENTION_DAYS` 改為 `1095`，代表三年。未取得前請維持一般保存限制。

## 本機資料

資料庫預設放在 `work/tai_v_pulse.sqlite3`。這個資料夾不會被提交到版本控制。建議定期備份資料庫，備份前先執行 `stop-local.ps1`。

電腦關機、睡眠或斷網期間無法記錄即時同接；恢復後能補抓頻道與影片目前資料，但不能還原漏掉的即時同接。
