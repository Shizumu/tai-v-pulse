# 台V Pulse

台V Pulse 是一套只在本機執行的台灣 VTuber YouTube 數據工具。它會尋找頻道名稱、頻道說明或頻道關鍵字中自述「台V」、「台灣 VTuber」或「Taiwan VTuber」的頻道，並只自動收錄公開訂閱數至少 1,000 的頻道。

## 第一次使用

1. 在 Google Cloud 建立專案並啟用 YouTube Data API v3。
2. 建立 API Key，但不要把 Key 貼到聊天或提交到版本控制。
3. 執行 `start-local.ps1`。第一次會建立並開啟 `.env`。
4. 將 Key 填入 `YOUTUBE_API_KEY=` 後儲存，再執行一次 `start-local.ps1`。
5. 瀏覽器會開啟 `http://localhost:3000`，按「探索台 V 頻道」。若不想自動開啟瀏覽器，可執行 `start-local.ps1 -NoOpen`。

停止服務時執行 `stop-local.ps1`。

## 指定頻道與誤判排除

- 「探索台 V 頻道」是大範圍搜尋，但只自動收錄頻道名稱、說明或關鍵字中自述為台 V，且公開訂閱數達 1,000 的頻道。
- 「指定 VTuber 搜尋」可輸入頻道名稱、`@handle`、Channel ID 或頻道網址。指定收錄不要求台 V 自述字樣，但仍須公開訂閱數達 1,000。
- 搜尋配額達到安全上限後，大範圍探索及僅輸入名稱的搜尋會暫停並顯示預計重置時間；頻道網址、`@handle` 與 Channel ID 仍可手動新增。
- 探索進行中會顯示目前關鍵字、頁次、候選數、新收錄、已更新、未達門檻與黑名單數，不再只留下「已開始」訊息。
- 已收錄頻道右側的「排除」會刪除該頻道的本機影片、統計與同接資料，並加入黑名單，之後大範圍探索不會自動加回。
- 若要收回黑名單頻道，可再次指定搜尋並按「重新收錄」。
- 自己的頻道可直接在「我的頻道」搜尋並加入；即使訂閱未滿 1,000 或隱藏訂閱數，也可作為私人分析基準，但不會混入公開收錄名單。

## 網頁內調整規則

在「收錄規則」右上角按「編輯」，可直接修改：

- 大範圍探索字樣
- 最低訂閱數
- 同接更新秒數
- 頻道統計更新間隔
- 最新上傳掃描間隔
- 資料保留天數

設定會保存在本機 SQLite 資料庫，重新啟動後仍會沿用。修改最低訂閱數或探索字樣只影響之後的探索與指定收錄，不會自動刪除既有頻道。

## 分類、組織、標籤與詳細頁

- 已確認頻道可設為「未分類、個人勢、企業勢、團體勢、其他」。首頁與頻道詳細頁都使用同一套可操作的分類選單。
- 頻道詳細頁可另外填入企業／團體名稱（例如「子午計畫」），以及多個手動標籤；這兩種資料不會與 YouTube 自述的「收錄依據」混在一起。
- 頻道列表可依分類或組織篩選，並依訂閱數、總觀看、影片數、分類、組織、名稱或最近更新排序；搜尋也會包含組織與手動標籤。
- 點擊頻道名稱可開啟詳細頁，查看訂閱趨勢、總觀看、影片與直播統計、最高同接、收錄依據、組織及手動標籤。
- 趨勢與最高同接必須先累積至少兩次統計快照或直播輪詢，剛收錄時可能暫時沒有圖表。
- 系統會依頻道自述及最後公開活動時間標示「活動中、休止中、疑似已畢業、狀態不明」；高把握的疑似狀態會進入待確認清單，使用者可手動確認或改回自動判斷。人工狀態不會被排程覆寫，確認畢業後若出現新活動則會提示檢查是否復出。

## 四個固定頁面

畫面上方會一直顯示「監測首頁」、「內容環境」、「趨勢圖表」及「我的頻道」四個切換按鈕，不需要先進入某一頁才能發現其他入口。

## 內容環境與同量級分析

進入「內容環境」，可用以下方式建立比較群組：

- 全部已收錄頻道
- 指定一個參考頻道，自動比較訂閱數為其 0.5～2 倍的頻道
- 固定訂閱級距：1,000～5,000、5,000～10,000、1 萬～5 萬、5 萬～10 萬、10 萬以上
- 再依頻道分類及最近 7、30、90 天篩選

內容環境會分析同級中位數及前 25%、每週發布頻率、觀看／訂閱比、直播同接／訂閱比、內容類型占比、直播時段熱圖、近期主題標籤、高效率內容和同級頻道案例。

內容主題由公開標題、標籤、影片分類及必要時的說明文字推測，目前包含遊戲、雜談、歌回、ASMR、音樂作品、紀念／重大活動與其他；內容形式分為直播、一般影片與 Shorts；聯動則是可與任何主題並存的附加屬性。歌回指以唱歌為主的直播，音樂作品指翻唱、原創曲、MV 等非直播作品；紀念／重大活動包含周年、生日、初配信、新衣裝、3D／Live2D 發表、畢業及大型里程碑。頻道說明中的「合作邀約」或「請勿提及其他頻道」不會單獨造成聯動誤判。這是可檢查的規則分類，不是 YouTube 官方 Analytics 分類。

- 各內容類型卡片可用滑鼠、鍵盤焦點或點擊查看最多 5 個不同頻道的代表內容。
- 「同級高效率內容」可切換一般影片、直播、Shorts 或全部；直播以同接／訂閱比排序，其餘以觀看／訂閱比排序。
- 設定自己的頻道後，內容環境會預設以該頻道為基準，使用 0.5～2 倍訂閱數的同級群組；仍可手動切換成固定級距或其他頻道。
- 資料在背景更新時不會整頁重載，因此閱讀位置與已開啟的內容不會每 30 秒跳回頁首。

程式會在後續影片更新時保存觀看、喜歡及留言快照。剛啟用時，既有影片只有目前值；持續運行後才會形成可靠的期間變化。

## 趨勢圖表與漲跌比較

「趨勢圖表」使用已保存在本機的公開快照，不會為了畫圖額外消耗 YouTube API 配額：

- 自動帶入「我的頻道」作為基準，但不把它納入同級中位數，以免自己影響比較基線。
- 可選全部頻道、基準頻道的 0.5～2 倍、固定量級、自訂訂閱範圍或最多 5 個指定頻道；也可保存常用比較組合。
- 可切換 7、30、90、365 天，以及直播、一般影片、Shorts、非 Shorts 主要內容或全部內容。
- 顯示訂閱排行、7／30 日成長、近期觀看中位數、公開觀看黏著度、同接／訂閱比、熱門內容與組織表現。
- 數字旁的箭頭表示與 30 天前相比上升、下降或持平；滑鼠移入、鍵盤聚焦或手機點擊箭頭才會展開目前值、基準值、差額與基準時間。
- 公開觀看黏著度定義為「最近 30 日內容觀看中位數 ÷ 目前訂閱數」，只適合公開量級比較，不等同 Studio 的回訪觀眾、觀眾留存或不重複觀眾。
- 未累積滿 7 或 30 天時顯示資料累積中，不會用不完整資料硬算漲跌。Studio 私人指標只疊加在自己的區塊，不參與其他頻道排行。

## 我的頻道與 YouTube Studio 匯入

「我的頻道」是只供自己的頻道使用的本機工作區。可先從監測首頁加入頻道，也可直接在本頁用名稱、`@handle`、Channel ID 或網址搜尋並設為自己的頻道：

- 先從既有收錄名單選定自己的頻道；公開訂閱、觀看、影片、直播與同接資料會直接沿用監測首頁的同一筆資料，不建立重複副本。
- 可上傳 YouTube Studio 進階模式匯出的 `.csv`、`.tsv` 或包含報表的 `.zip`。系統會先預覽辨識到的日期、影片及指標，再由使用者確認匯入。
- 支援觀看次數、觀看時間、平均觀看時長、曝光、點閱率、訂閱增減、喜歡、留言、分享與預估收益等常見欄位；實際可用內容取決於 Studio 匯出檔。
- 匯入資料會記錄來源批次及檔案雜湊，完全相同的檔案不會重複匯入；同一日期／影片／指標若出現不同值會標示衝突，保留來源供核查，不會靜默覆蓋。
- 可回復單一匯入批次，也能手動補上一筆指定日期與指標並留下備註。手動資料會與 Studio 匯入資料分開保存。
- 原始上傳檔不會保存；解析後的結構化數據只寫入本機 SQLite。上傳前仍建議檢查檔案內容，不要匯入不需要保存的敏感資訊。

YouTube Studio 目前的進階模式可下載目前畫面的報表；若報表超過介面可匯出的 500 列，需縮小日期／篩選範圍分批下載，或另行使用 YouTube Reporting API。

## 預設規則

- 訂閱門檻：1,000
- 同接更新：每 60 秒，最多 50 支直播合併成一次 API 請求
- 頻道統計：每 6 小時
- 最新上傳掃描：每 4 小時，分批執行
- API 一般配額安全保留：10%
- 原始統計保留：30 天
- 隱藏訂閱數：放入待審核，不自動收錄

所有設定都在 `.env`。取得 YouTube 相應的長期統計保存許可後，可將 `RETENTION_DAYS` 改為 `1095`，代表三年。未取得前請維持一般保存限制。

## 本機資料

資料庫預設放在 `work/tai_v_pulse.sqlite3`。頻道設定、監測快照、Studio 匯入與手動補充都保存在這裡；此資料夾不會被提交到版本控制。建議定期備份資料庫，備份前先執行 `stop-local.ps1`。

電腦關機、睡眠或斷網期間無法記錄即時同接；恢復後能補抓頻道與影片目前資料，但不能還原漏掉的即時同接。

頁首可切換淡綠、淡粉、淡藍、淡紫與淡黃主題；偏好只保存在目前瀏覽器。
