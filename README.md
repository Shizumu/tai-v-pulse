# 台V Pulse

台V Pulse 是一套只在本機執行的台灣 VTuber YouTube 數據工具。它會尋找頻道名稱、頻道說明或頻道關鍵字中自述「台V」、「台灣 VTuber」或「Taiwan VTuber」的頻道，並只自動收錄公開訂閱數至少 1,000 的頻道。

執行環境需要 Windows PowerShell、Node.js 22.13.0 以上及 Python 3.11 以上。Windows 對外測試版提供單檔安裝 EXE；使用者不需要執行程式碼建置或輸入 npm／Python 指令，圖形化啟動器會檢查缺少的環境、引導官方安裝、顯示可查閱的錯誤代碼，並可匯出已移除敏感資訊的診斷 LOG。精簡安裝、安全與限制說明請先閱讀 [PUBLIC_RELEASE.md](PUBLIC_RELEASE.md)。

## 第一次使用

1. 在 Google Cloud 建立專案並啟用 YouTube Data API v3。
2. 建立 API Key，但不要把 Key 貼到聊天、診斷報告或版本控制。
3. 核對隨附 SHA-256 後，雙擊 `tai-v-pulse-0.8.3-setup.exe`，閱讀說明並按「安裝並啟動」。安裝位置是目前使用者的 `%LOCALAPPDATA%\Programs\TaiVPulse`，不需要管理員權限。
4. 若缺少 Node.js 22.13.0 以上或 Python 3.11 以上，啟動器會提供 WinGet 自動安裝、開啟官方下載頁或取消三種選項；安裝完成後重新開啟啟動器。
5. 啟動器會在台V Pulse 自己的 `work/python-packages` 準備 Windows 所需的 Python 時區資料，並在尚未安裝前端套件時詢問是否自動安裝；使用者不需要自行輸入 pip 或 npm 指令。
6. 只要 `.env` 不存在或 `YOUTUBE_API_KEY` 尚未填寫，程式就會建立並開啟設定檔。填入自己的 Key 並儲存，再回到啟動器按一次「啟動」。
7. 瀏覽器會開啟 `http://127.0.0.1:3000`，即可按「探索台 V 頻道」。

若 `.env` 中有多個 `YOUTUBE_API_KEY`，程式會採用最後一行；等號前後空白、單／雙引號及 `export YOUTUBE_API_KEY=...` 皆可辨識。可執行 `start-local.ps1 -CheckEnv` 檢查設定格式，輸出只會顯示是否辨識成功，不會顯示金鑰內容。

平常從桌面或開始功能表的「台V Pulse」開啟啟動器，即可啟動、停止、開啟網頁、編輯 API Key、匯出診斷報告或解除安裝。啟動器的「後台動態」會顯示正在探索頻道、更新直播同接、掃描最新上傳、更新頻道公開數據或手動新增頻道，工作結束後也會保留最近完成／未完成的項目。覆蓋安裝新版會保留 `.env`、`work/`、SQLite 與本機分析資料，並清除已由新版淘汰的程式檔。解除安裝時可選擇保留資料，或在再次確認後永久刪除所有台V Pulse 本機資料。原始碼測試包仍可使用 `啟動台V Pulse.cmd`、`停止台V Pulse.cmd`、`start-local.ps1` 與 `stop-local.ps1`。

## 問題回報與 LOG

啟動或安裝失敗時會顯示固定錯誤代碼，例如：

- `TVP-I…`：安裝或更新問題。
- `TVP-E201`：缺少 Node.js 或 Python。
- `TVP-E301`：尚未設定 YouTube API Key。
- `TVP-E401`／`TVP-E402`：npm 或前端套件安裝問題。
- `TVP-E403`：Python 時區資料安裝問題。
- `TVP-E501`／`TVP-E502`：資料服務或網頁服務未能啟動。
- `TVP-D001`：診斷報告建立失敗。

按啟動器的「匯出診斷報告」，桌面會產生 `TaiVPulse-diagnostics-日期時間.zip`。報告包含最近的安裝、啟動、前端與後端 LOG，以及 Windows、Node.js、Python 和本機埠的基本狀態；它不包含 `.env`、API Key、SQLite 資料庫、Studio 原始檔，並會遮蔽 Windows 使用者名稱與電腦名稱。回報時請提供錯誤代碼及這個 ZIP。

目前安裝程式未經程式碼簽章，Windows SmartScreen 可能顯示「未知發行者」。正式對外提供時應同時發布 `.sha256` 檔供核對；這只能驗證下載內容一致，不能取代程式碼簽章。

## 指定頻道與誤判排除

- 「探索台 V 頻道」是大範圍搜尋，但只自動收錄頻道名稱、說明或關鍵字中自述為台 V，且公開訂閱數達 1,000 的頻道。
- 「指定 VTuber 搜尋」可輸入頻道名稱、`@handle`、Channel ID 或頻道網址。指定收錄不要求台 V 自述字樣，但仍須公開訂閱數達 1,000。
- 搜尋配額達到安全上限後，大範圍探索及僅輸入名稱的搜尋會暫停並顯示預計重置時間；頻道網址、`@handle` 與 Channel ID 仍可手動新增。
- 探索進行中會顯示目前關鍵字、頁次、候選數、新收錄、已更新、未達門檻與黑名單數，不再只留下「已開始」訊息。
- 已收錄頻道右側的「排除」會刪除該頻道的本機影片、統計與同接資料，並加入黑名單，之後大範圍探索不會自動加回。
- 若要收回黑名單頻道，可再次指定搜尋並按「重新收錄」。
- 自己或團隊藝人的頻道可直接在「頻道工作區」搜尋並加入；即使訂閱未滿 1,000 或隱藏訂閱數，也可作為私人分析基準，但不會混入公開收錄名單。
- 每次手動收錄後會顯示分類引導，可設定勢別、企業／團體、標籤與活動狀態。新頻道會進入待更新佇列，滿 50 個自動批次更新，也可隨時按「立即更新這一批」。

## 網頁內調整規則

在「收錄規則」右上角按「編輯」，可直接修改：

- 大範圍探索字樣
- 最低訂閱數
- 同接更新秒數
- 頻道統計更新間隔
- 最新上傳掃描間隔
- 對外發布版的公開 API 快照保留期限（7、14 或 30 天）
- 作者私人本機版的公開快照保留期限（7 天至永久）
- 我的頻道匯入資料保留期限（一個月至永久）

設定會保存在本機 SQLite 資料庫，重新啟動後仍會沿用。修改最低訂閱數或探索字樣只影響之後的探索與指定收錄，不會自動刪除既有頻道。

## 分類、組織、標籤與詳細頁

- 已確認頻道可設為「未分類、個人勢、企業勢、團體勢、其他」。首頁與頻道詳細頁都使用同一套可操作的分類選單。
- 頻道詳細頁可另外填入企業／團體名稱（例如「子午計畫」），以及多個手動標籤；這兩種資料不會與 YouTube 自述的「收錄依據」混在一起。
- 頻道列表可依分類或組織篩選，並依訂閱數、總觀看、影片數、分類、組織、名稱或最近更新排序；搜尋也會包含組織與手動標籤。
- 點擊頻道名稱可開啟詳細頁，查看訂閱趨勢、總觀看、影片與直播統計、最高同接、收錄依據、組織及手動標籤。
- 趨勢與最高同接必須先累積至少兩次統計快照或直播輪詢，剛收錄時可能暫時沒有圖表。
- 系統會依頻道自述及最後公開活動時間標示「活動中、休止中、疑似已畢業、狀態不明」；高把握的疑似狀態會進入待確認清單，使用者可手動確認或改回自動判斷。人工狀態不會被排程覆寫，確認畢業後若出現新活動則會提示檢查是否復出。

## 四個固定頁面

畫面上方會一直顯示「監測首頁」、「內容環境」、「趨勢圖表」及「頻道工作區」四個切換按鈕，不需要先進入某一頁才能發現其他入口。

## 內容環境與同量級分析

進入「內容環境」，可用以下方式建立比較群組：

- 全部已收錄頻道
- 指定一個參考頻道，自動比較訂閱數為其 0.5～2 倍的頻道
- 固定訂閱級距：1,000～5,000、5,000～10,000、1 萬～5 萬、5 萬～10 萬、10 萬以上
- 再依頻道分類及最近 7、30、90 天篩選

內容環境會分析同級中位數及前 25%、每週發布頻率、觀看／訂閱比、直播同接／訂閱比、內容類型占比、直播時段熱圖、近期主題標籤、高效率內容和同級頻道案例。

內容主題由公開標題、標籤、影片分類及必要時的說明文字推測，目前包含遊戲、雜談、歌回、ASMR、音樂作品、紀念／重大活動與其他；內容形式分為直播、一般影片與 Shorts；聯動則是可與任何主題並存的附加屬性。歌回指以唱歌為主的直播，音樂作品指翻唱、原創曲、MV 等非直播作品；紀念／重大活動包含周年、生日、初配信、新衣裝、3D／Live2D 發表、畢業及大型里程碑。頻道說明中的「合作邀約」或「請勿提及其他頻道」不會單獨造成聯動誤判。這是可檢查的規則分類，不是 YouTube 官方 Analytics 分類。

- 各內容類型卡片可用滑鼠、鍵盤焦點或點擊查看最多 5 個不同頻道的代表內容。
- 「同級高效率內容」可切換一般影片、直播、Shorts 或全部；直播以同接／訂閱比排序，其餘以觀看／訂閱比排序。
- 設定自己的頻道後，內容環境會預設以該頻道為基準，使用 0.5～2 倍訂閱數的同級群組；仍可手動切換成固定級距或其他頻道。
- 資料在背景更新時不會整頁重載，因此閱讀位置與已開啟的內容不會每 30 秒跳回頁首。

程式會在後續影片更新時保存觀看、喜歡及留言快照。剛啟用時，既有影片只有目前值；持續運行後才會形成可靠的期間變化。

## 趨勢圖表與漲跌比較

「趨勢圖表」使用已保存在本機的公開快照，不會為了畫圖額外消耗 YouTube API 配額：

- 自動帶入頻道工作區目前選取的頻道作為基準，但不把它納入同級中位數，以免自己影響比較基線。
- 可選全部頻道、基準頻道的 0.5～2 倍、固定量級、自訂訂閱範圍或最多 5 個指定頻道；也可保存常用比較組合。
- 可切換 7、30、90、365 天，以及直播、一般影片、Shorts、非 Shorts 主要內容或全部內容。
- 顯示訂閱排行、7／30 日成長、近期觀看中位數、公開觀看黏著度、同接／訂閱比、熱門內容與組織表現。
- 數字旁的箭頭表示與 30 天前相比上升、下降或持平；滑鼠移入、鍵盤聚焦或手機點擊箭頭才會展開目前值、基準值、差額與基準時間。
- 公開觀看黏著度定義為「最近 30 日內容觀看中位數 ÷ 目前訂閱數」，只適合公開量級比較，不等同 Studio 的回訪觀眾、觀眾留存或不重複觀眾。
- 未累積滿 7 或 30 天時顯示資料累積中，不會用不完整資料硬算漲跌。Studio 私人指標只疊加在自己的區塊，不參與其他頻道排行。

## 頻道工作區與 YouTube Studio 匯入

「頻道工作區」同時支援個人與企業 STAFF：個人可只加入自己的頻道，團隊則可加入多位藝人並並排比較。可先從監測首頁加入，也可直接在本頁用名稱、`@handle`、Channel ID 或網址搜尋：

- 從既有收錄名單加入一個或多個管理頻道；公開訂閱、觀看、影片、直播與同接資料會直接沿用監測首頁的同一筆資料，不建立重複副本。
- 工作區會顯示團隊合計、30 天變化、近 30 天內容量、最高同接及多頻道比較表；點擊頻道卡片即可切換個別公開歷史、近期內容與私人資料。
- 公開監測摘要與 Studio 私人摘要分開標示。公開歷史會自動同步；Studio 匯入與手動補值則依目前選取的藝人頻道隔離保存。
- 可上傳 YouTube Studio 進階模式匯出的 `.csv`、`.tsv` 或包含報表的 `.zip`。系統會先預覽辨識到的日期、影片及指標，再由使用者確認匯入。
- 支援觀看次數、觀看時間、平均觀看時長、曝光、點閱率、訂閱增減、喜歡、留言、分享與預估收益等常見欄位；實際可用內容取決於 Studio 匯出檔。
- 匯入資料會記錄來源批次及檔案雜湊，完全相同的檔案不會重複匯入；同一日期／影片／指標若出現不同值會標示衝突，保留來源供核查，不會靜默覆蓋。
- 可回復單一匯入批次，也能手動補上一筆指定日期與指標並留下備註。手動資料會與 Studio 匯入資料分開保存。
- 原始上傳檔不會保存；解析後的結構化數據只寫入本機 SQLite。上傳前仍建議檢查檔案內容，不要匯入不需要保存的敏感資訊。

YouTube Studio 目前的進階模式可下載目前畫面的報表；若報表超過介面可匯出的 500 列，需縮小日期／篩選範圍分批下載，或另行使用 YouTube Reporting API。

## 預設規則

- 訂閱門檻：1,000
- 同接更新：每 60 秒，最多 50 支直播合併成一次 API 請求
- 頻道統計：每 6 小時
- 最新上傳掃描：每 4 小時，分批執行
- API 一般配額安全保留：10%
- 公開 API 快照保留：30 天
- 頻道工作區 Studio／手動資料保留：預設永久
- 隱藏訂閱數：放入待審核，不自動收錄

介面中的監控頻率與資料保存期限均使用固定選項。`TAI_V_PULSE_EDITION=public` 是日後對外提供的預設模式，公開頻道、影片及同接快照最多保存 30 天。作者自己的 `.env` 使用 `personal`，可在本機選擇半年、1、2、3、5、10 年或永久保存；這個選擇不會寫入 `.env.example` 或對外套件。Studio 報表與手動補充資料預設永久保存。延長或縮短期限時，介面會提示容量、備份及刪除風險。

## 本機資料

資料庫預設放在 `work/tai_v_pulse.sqlite3`。頻道設定、監測快照、Studio 匯入與手動補充都保存在這裡；此資料夾不會被提交到版本控制。建議定期備份資料庫，備份前先執行 `stop-local.ps1`。

電腦關機、睡眠或斷網期間無法記錄即時同接；恢復後能補抓頻道與影片目前資料，但不能還原漏掉的即時同接。

頁首可切換淡綠、淡粉、淡藍、淡紫與淡黃主題；偏好只保存在目前瀏覽器。

## 開發與檢查

```powershell
python -m unittest tests.test_collector
npm run build
node --test tests/rendered-html.test.mjs
```

建立不含 `.env`、`work/`、SQLite、Studio 原始檔、依賴及建置快取的對外測試包：

```powershell
.\scripts\package-public.ps1
```

建立同樣經過白名單檢查的單檔 Windows 安裝程式與 SHA-256：

```powershell
.\scripts\build-windows-installer.ps1
```

腳本會以白名單複製必要執行檔案，在 `outputs/` 產生版本化 ZIP 與 SHA-256 校驗檔；若同名輸出已存在則停止，不會覆寫既有套件。

本工具僅使用官方 YouTube Data API，不爬取 YouTube 網頁，也不是 YouTube 官方產品。對外發布模式首次使用會要求閱讀並同意本機資料、YouTube 平台條款與非商用授權聲明；作者私人本機模式不顯示這個發布版確認視窗。完整內容可從每頁頁尾的「使用、隱私與授權聲明」開啟。
